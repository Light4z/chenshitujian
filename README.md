# 建城图鉴

《模拟城市：我是市长》小程序的非官方玩家建筑图鉴，收录建筑分类、占地面积、覆盖区域、增益效果及建筑图片。

## 使用

在线访问：<https://light4z.github.io/chenshitujian/>

本地使用时直接用浏览器打开 `index.html`。`assets` 文件夹包含全部建筑图片，必须与 HTML 文件放在同一目录。

## 内容

- 268 个图鉴条目
- 377 张建筑图片
- 按住宅、区域服务、基础资源、人文服务、城市发展分类
